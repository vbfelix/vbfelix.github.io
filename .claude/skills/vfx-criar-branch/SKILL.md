# Criar branch

Confira status, branch atual e referências necessárias. Preserve alterações rastreadas e não rastreadas. Use a convenção local; se ausente, use `codex/<assunto-em-kebab-case>`. Não use stash, reset, clean ou mudança de upstream automaticamente.
